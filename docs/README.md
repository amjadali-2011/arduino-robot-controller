# Project documentation

Use this folder for wiring and setup notes.

## Recommended documents

- `wiring.md` — confirmed pin-by-pin connections for each controller.
- `parts-list.md` — board versions, driver, sensors, display modules, and power supplies.
- `troubleshooting.md` — error messages and fixes that have been verified.

## Important

The project notes mention an L298N motor driver, HC-05 Bluetooth module, pulse sensor, temperature sensor, and LED-matrix eyes. Treat these as a working parts list, not a final wiring specification. Record exact module versions and pin assignments only after checking the actual build.

When documenting a circuit, include the board model, supply voltage, ground connections, and any required libraries. Never assume a pin map from a different sketch applies to this one.
